# Changelog

## V0.5.0 — Forest Community Ecology

- 保留 V0.1–V0.4.1 的地形、探索、洞穴、动物行为、种群动力学、动态植被网格。
- 新增五树种性状模型：阔叶树、针叶树、白桦、溪柳、古杉。
- 新增树木根系生物量、根系半径、根深、根系健康与网格化根系压力。
- 根系竞争实际扣除土壤水分与养分，并反馈树木健康与幼苗建立。
- 新增突出层、林冠层、亚林冠层、幼树层统计。
- 新增火灾、风倒、洪水、病虫害局地扰动模型。
- 三维场景新增地表根脉、树种差异化树冠、倒木、焦黑枯木与扰动地表斑块。
- 生态观察面板新增森林群落数据与四种手动扰动实验按钮。
- 新增 70 次森林群落多随机种子实验与完整回归。
- 修复 V0.4.1 顶点着色器使用但未声明 `uTime` 的源码问题。
- 真实 GPU / WebGL2 视觉验收仍需在本机完成。
