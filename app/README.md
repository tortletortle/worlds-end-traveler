# 《世界尽头的旅行者》V0.5 — 雾隐树海森林群落版

V0.5 在 V0.4.1 的完整三维探索原型上，加入多树种森林群落、空间根系竞争、垂直林层、自然扰动与可交互的扰动实验。工程不依赖外部 CDN，可离线运行。

## Windows 运行

1. 解压工程 ZIP。
2. 进入 `app` 文件夹。
3. 在 PowerShell / CMD 执行：

   ```powershell
   py -m http.server 8000
   ```

4. 打开 `http://127.0.0.1:8000/`。
5. 点击“进入雾隐树海”。建议开启浏览器硬件加速。

## 操作

- `W A S D`：移动
- 鼠标：观察 / 转向（点击画面锁定鼠标）
- `Shift`：奔跑
- `Space`：跳跃
- `E`：观察动物或地标；进入 / 离开根脉洞穴
- `M`：探索地图
- `I`：生态观察面板
- `Esc`：释放鼠标

## 版本继承

### V0.1–V0.4.1

完整继承原有森林地形、河流瀑布、村落与遗迹、洞穴、探索路线、四种动物行为、繁殖与种群动力学、空间植被生长、树木动态网格、季节落叶、动物取食与践踏痕迹。原有入口、地图、移动、地标交互和生态面板保留。

### V0.5 新增

#### 1. 五树种群落

- 阔叶树（broadleaf）
- 针叶树（pine）
- 白桦（birch）
- 溪柳（willow）
- 古杉（cedar）

树种有不同的耐阴、耐旱、需水量、根系扩展、根深、抗火、抗风和寿命参数。初始林木按种子与局地环境确定树种；新生幼苗按水分、林下光照和扰动条件选择树种。

#### 2. 根系网络与地下资源竞争

每株树维护根系生物量、根系半径、根深与根系健康。根系对邻近 16×16 空间植被网格施加高斯衰减的根系压力。局地根系压力转化为水分与养分吸收，影响土壤水分、养分、树木健康和幼苗建立。

根系的地表延伸会生成可见三维根脉网格；树木长大时根系范围随之扩展。该版本显示的是地表根脉/根张结构，地下三维根尖拓扑与根系分枝生长尚未实现。

#### 3. 垂直森林结构

每株活树按尺寸划分为突出层、林冠层、亚林冠层和幼树层。每个空间单元统计活树数量、树种丰富度和林冠覆盖，生态面板展示林地覆盖与垂直层次。

#### 4. 自然扰动

- 火灾：受枯落物、草本燃料、局地干燥度和树种抗火性影响；消耗林下植被、种子库与枯落物，损伤林木，形成焦黑地表和林窗。
- 风倒：根据树木尺寸、树种抗风性和距离计算倒伏风险；倒木会以横卧木形态保留。
- 洪水：提高局地土壤水分和养分，同时冲刷部分幼苗并损伤树木。
- 病虫害：针对目标树种造成健康损失与林冠稀疏斑块。

生态面板提供四个手动扰动按钮，可在玩家当前位置附近触发实验。日常世界也有低概率自然扰动。

#### 5. 根系竞争对照

实验可关闭根系水分 / 养分吸收作为消融对照。关闭后保留根系压力计算和根系可视化，但不从土壤中扣除水分与养分。用于验证根系吸收是否真实改变环境状态。

## 时间与模型边界

- 1 个生态日约对应 300 秒游戏时间；生态模型在每日步长更新。
- 1 年 120 个生态日，每季 30 日。
- 参数为游戏可玩性设计的加速模型，不是经过野外数据校准的生态预测模型。
- 根系使用网格化影响核近似资源竞争；尚未模拟真实土壤剖面、菌根网络、地下水流、根系解剖学或根尖连续生长。
- 火灾、洪水、风倒和病虫害为局地事件模型；尚未实现流体力学火线传播、气象场耦合或真实病原体传播。
- 当前仍为约 240m × 240m 单区域样板，不是最终无缝开放世界。

## 图形验收边界

自动化回归使用 WebGL2 API 测试替身验证 JavaScript、DOM、场景网格构建调用、生态状态与交互，不等于真实 GPU 渲染。已尝试 Chromium SwiftShader WebGL2，但当前运行容器仍未提供 WebGL2 上下文。因此真实 GPU 着色器编译、最终视觉质量与 FPS 必须在本机支持 WebGL2 的 Chrome / Edge 上验收。

V0.5 修复了 V0.4.1 顶点着色器使用 `uTime` 却未在顶点着色器声明该 uniform 的源码问题；静态源码检查已覆盖此项，但未宣称真实 GPU shader compile 已通过。

### V0.6.1 树冠结构实验（同一视觉分支）

在蕨类林下实验之后，继续替换树木的简化树冠：
- 阔叶树与白桦：由少量大球体改为确定性分布的多簇冠层，并显式生成支撑枝。
- 白桦：增加浅色树皮与横向深色树皮环带，冠形更窄。
- 垂柳：增加向外延伸并下垂的枝条与细长叶簇。
- 松树 / 古杉：由层叠球冠改为分层外展枝条和三角形针叶束；古杉层数更多、冠形更窄。
- 所有树形由树木种子决定，生态刷新后同一棵树保持稳定外观；健康度和季节仍控制叶量与颜色。

**待验证：** 当前是程序化低多边形树形升级，不是扫描级或照片级资产。需要在硬件 WebGL2 环境中检查树冠远景轮廓、枝叶穿插、不同树种辨识度、森林整体密度与帧时间。特别注意针叶束的三角形数量可能增加 CPU 构建与 GPU 顶点负担；在测得性能前不要合并主线。
