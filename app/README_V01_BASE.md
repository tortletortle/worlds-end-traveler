# 《世界尽头的旅行者》V0.1 — 雾隐树海

一个离线可运行的第一人称 3D 探索原型。使用原生 WebGL 2.0 和 JavaScript 编写，不依赖 CDN、npm 包或外部模型资源。当前样板区覆盖约 240m × 240m 的程序化地形范围（按 1 世界单位约等于 1 米估算），它是单一区域关卡原型，不代表最终 30 km² 世界规模。

## 运行

1. 解压项目。
2. 使用最新版 Chrome 或 Edge 打开 `index.html`。
3. 点击“进入雾隐树海”。建议使用鼠标和键盘。

如果浏览器禁用了本地文件 WebGL，可在项目目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 操作

- `W A S D`：移动
- 鼠标：观察 / 转向（点击画面锁定鼠标）
- `Shift`：奔跑
- `Space`：跳跃
- `E`：观察附近地标；在根脉洞穴入口进入 / 离开
- `M`：打开 / 关闭地图
- `Esc`：释放鼠标
- 方向键：备用视角控制

## V0.1 已实现

- 程序化起伏地形、山坡和断层高差（约 240m × 240m 样板范围）
- 白冠河上游与下游、动态水面、白冠瀑布和下游水潭
- 程序化森林、针叶树、巨型千冠母树、树根和岩石
- 林息村木屋聚落、古桥、树海断城、低语林庭
- 根脉洞穴入口与可进入的洞穴内部场景
- 多条泥土探索路径、地标交互、探索记录和区域地图
- 第一人称移动、奔跑、跳跃、基础碰撞和雾效

## 已知限制

- 本版是灰盒 / 程序化美术原型，树叶、房屋、洞穴和遗迹均为程序网格，不是最终高精度美术资产。
- 当前没有完整动物 AI、任务系统、存档系统、动态季节或完整生态模拟。
- 地形与路径碰撞采用轻量近似；部分装饰物没有独立碰撞体。
- 当前洞穴通过入口交互切换到独立洞内场景，不是连续无缝的地形挖洞。
- 画面采用实时方向光和距离雾；尚未实现真实阴影、PBR 材质或物理水体。

## 测试

自动化冒烟测试：

```bash
python tests/smoke_test.py
```

测试需要本机 Chromium 和 Python Playwright。脚本会启动本地 HTTP 服务，检查 WebGL2 初始化、地标清单、地形网格、洞穴切换、地图绘制以及截图输出。
