## 关键因果检查

- 同一随机种子重复运行，结果一致。
- 10 个配对种子中，启用根系资源吸收的基准情景均比关闭根系吸收情景具有更低平均土壤水分；消融组根系吸水量为 0。
- 五个树种在所有基准种子实验中均被观察到。
- 严重干旱组平均土壤水分低于基准组，干旱压力日和树木死亡高于基准组。
- 火灾、风倒、洪水、病虫害均在各自 10 个种子实验中正确触发，且产生可测树木损伤。
- 基准组没有被强制扰动污染。
- 状态量保持在设定边界内，无 NaN / Infinity。

## GPU 验收限制

自动化浏览器回归注入 WebGL2 API 测试替身，主要验证场景构建与交互状态。另尝试 Chromium SwiftShader WebGL2，当前容器仍返回 `webgl2=false`。因此真实 GPU shader 编译、最终画面、阴影与 FPS **未验收**。V0.4.1 顶点着色器缺失的 `uTime` uniform 声明已修复，并加入静态源码检查；不能据此声称 GPU 编译通过。
