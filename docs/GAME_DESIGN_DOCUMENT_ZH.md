# 《世界尽头的旅行者》游戏设计文档（GDD）

- 文档版本：0.2
- 对应开发分支：`feature/demo-lost-road`
- 当前产品阶段：第一段可玩叙事 Demo
- 核心方向：自由探索 + 隐藏故事（方向 B）

## 1. 产品愿景

《世界尽头的旅行者》是一款以自然探索、生态观察和环境叙事为核心的单人第一人称开放世界游戏。

玩家来到阿尔维拉，不是为了拯救世界或完成一条强制任务链，而是为了旅行、观察、发现，并逐渐理解这个世界。

世界独立于玩家运行：森林生长，动物觅食、饮水和迁徙，季节改变植被与环境。故事隐藏在地理、遗迹、自然现象和居民留下的痕迹中。

**设计支柱**
1. 自由旅行：主线提供方向，但不阻止玩家偏离道路。
2. 发现驱动：奖励来自观察、理解和建立联系，而不是刷数值。
3. 世界可信：生态变化要能在环境中被玩家感知。
4. 环境叙事：尽量让地点、物件、声音和空间关系讲故事。
5. 低压力节奏：不使用倒计时、每日任务或强制战斗制造压力。

## 2. 类型与体验定位

| 项目 | 设计 |
|---|---|
| 类型 | 第一人称探索冒险 / 自然生态模拟 |
| 模式 | 单人、优先离线 |
| 核心活动 | 行走、观察、发现、记录、推理 |
| 主要成长 | 地图知识、自然知识、历史认知 |
| 叙事形式 | 可选主线线索 + 碎片化环境叙事 |
| 美术 | 风格化自然写实，强调层次、光照和可读性 |
| 目标玩家 | 喜欢探索、自然、氛围和非线性叙事的玩家 |

## 3. 世界与首发区域

### 3.1 阿尔维拉

阿尔维拉是一个由不同生态区域和古代文明遗迹构成的幻想世界。游戏不在开场完整解释世界历史，玩家通过旅行逐渐拼出过去。

### 3.2 雾隐树海

当前首个可玩区域，约 240m × 240m 的开发样板。它是玩法验证区，不代表最终世界规模。

现有地点：
- 林息村
- 雾桥古道
- 白冠瀑布
- 鹿踪浅滩
- 根脉洞穴
- 低语林庭
- 树海断城
- 千冠母树

当前世界已有森林地形、河流、瀑布、村落、遗迹、洞穴、动物行为、种群动力学、空间植被生长、季节变化和森林群落扰动模型。

## 4. 核心游戏循环

**自由旅行 → 注意到异常 → 靠近观察 → 发现线索 → 写入手记 → 建立地点联系 → 选择下一段旅程。**

短循环：在一个地点发现一项新信息。

中循环：串联多个地点的线索，理解一个局部谜团。

长循环：通过季节、生态和历史记录，逐渐理解阿尔维拉。

主线不是唯一活动。玩家随时可以观察动物、偏离路线或返回已探索地点。

## 5. 第一段 Demo：《消失的古道》

### 5.1 Demo 目标

验证“自由探索 + 隐藏故事”是否能形成有吸引力的玩法闭环。

目标体验时长：约 5–10 分钟，需通过实际试玩测量后校准。当前不宣称已经达到该时长或完成玩家测试。

### 5.2 故事梗概

玩家在林息村发现一块被苔藓覆盖的旧路标。刻文提到雾桥。桥下文字指向九根石柱，石柱的回响指向树海断城。断城壁画又把道路引向千冠母树。最终，玩家发现古道并未消失，而是沿着巨树根系通往地下的根脉洞穴。

结尾不解释所有谜团。石阶继续向地下延伸，为下一段旅程留下悬念。

### 5.3 线索流程

| 顺序 | 地点 | 发现 | 下一步 |
|---|---|---|---|
| 1 | 林息村 | 旧路标背面的刻痕，提到雾桥 | 前往雾桥古道 |
| 2 | 雾桥古道 | 桥下石刻，提到九声低语和旧城 | 前往低语林庭 |
| 3 | 低语林庭 | 九根石柱与树根祭坛产生回响 | 前往树海断城 |
| 4 | 树海断城 | 壁画描绘沿树根修建的道路 | 前往千冠母树 |
| 5 | 千冠母树 | 主根围出地下入口，古道通向根脉 | 前往根脉洞穴 |
| 6 | 根脉洞穴 | 被掩埋的石阶继续深入地下 | 第一章结束 |

### 5.4 线索规则

- 玩家可以自由前往任何地点，不设置空气墙或强制传送。
- 提前发现后续地点时，只提示“线索尚缺少前文”，不提前泄露答案。
- 回到该地点且前置线索已解锁后，可以正常记录。
- 主线线索与普通地标发现分开处理。
- 普通动物观察和生态探索不受主线进度限制。

## 6. 旅行手记

旅行手记是连接探索与长期成长的核心界面。

第一段 Demo 只实现“古道线索”栏目。后续再扩展：
- 地理记录：地标、河流、洞穴和路线。
- 动物图鉴：物种、行为、栖息地和观察日期。
- 植物图鉴：树种、草本、季节变化。
- 自然记录：天气、灾害和生态变化。
- 历史档案：遗迹、铭文和文明线索。

手记应记录玩家实际发现的内容，不应把未发现的信息提前展示为已知。

## 7. 生态系统与玩家关系

生态系统不是独立的后台模拟器。每个重要系统都应回答：玩家能观察到什么、能理解什么、能做什么。

| 模拟系统 | 玩家可感知反馈 | 后续玩法方向 |
|---|---|---|
| 动物行为 | 饮水、觅食、躲避、休息 | 跟踪、观察、图鉴 |
| 植被演替 | 林窗、幼苗、季节颜色 | 跨季节记录 |
| 根系竞争 | 林木生长差异、裸露根系 | 生态观察 |
| 自然扰动 | 倒木、焦痕、洪水痕迹 | 环境变化调查 |
| 季节时间 | 植被、动物活动与光照变化 | 周期性旅行 |

开发调试按钮（例如手动触发火灾、推进生态时间）属于开发工具，不应直接作为正式玩家 UI。

## 8. 交互与界面

当前基础操作：
- WASD：移动
- 鼠标：观察方向
- Shift：奔跑
- Space：跳跃
- E：观察 / 交互
- M：地图
- J：旅行手记
- I：生态观察（开发实验界面，正式版本需重新定位）

当前 Demo 新增：
- 当前旅程目标卡片。
- 地图上的当前线索标记。
- 旅行手记面板。
- 线索进度。
- 第一章结束界面。

界面应克制、沉浸，避免把屏幕变成任务管理后台。

## 9. 叙事原则

- 不用大段开场旁白解释世界。
- 不把所有故事交给 NPC 对话。
- 线索应有空间依据，玩家能理解为什么它出现在这里。
- 允许玩家错过、提前发现或稍后返回。
- 保留未解之谜，不在第一章解释整个世界。
- 不用强制战斗打断探索节奏。

## 10. Demo 验收标准

### 功能验收
1. 新玩家能从入口开始游戏。
2. 玩家能看到当前旅程目标。
3. 六个故事地点能按顺序推进线索。
4. 提前访问后续地点不会跳过章节。
5. 已记录线索显示在旅行手记中。
6. 地图能标记当前目标地点。
7. 进入根脉洞穴后出现第一章结束界面。
8. 关闭结束界面后仍可继续自由探索。
9. 普通地标与动物观察仍然可用。

### 质量验收
- 浏览器无未处理 JavaScript 异常。
- 原有移动、地图、洞穴和生态回归通过。
- UI 在桌面与窄屏布局下不遮挡关键操作。
- 真实 WebGL2 GPU 环境完成画面检查。
- 至少邀请 3 名未参与开发的玩家试玩，记录是否理解目标、是否愿意继续探索、哪里感到迷路或无聊。

### 证据要求
区分代码检查、自动化测试、真实 GPU 画面、玩家试玩四类证据。没有实测的项目标记为待验收。

## 11. 当前 Demo 的边界

本 Demo 是一段叙事与探索纵切片，不代表完整游戏。

尚未实现：
- 真正可见、可拾取的实体线索物件与专用调查动画。
- NPC 对话与村民日常。
- 脚步、风、瀑布和石柱的空间音频叙事。
- 旅行手记跨会话存档。
- 复杂谜题和多结局。
- 其他生态区域。
- 正式发布级 GPU 画面和性能验收。

这些不应在 Demo 文案中被描述为已完成。

## 12. 研发优先级

P0：保证第一段 Demo 从开始到结尾完整可玩，修复交互和 UI 阻断。

P1：将文字线索变成场景内可见的调查对象，加入调查动作和环境音。

P2：完善动物观察与旅行手记，让自然生态成为第二条可持续玩法线。

P3：扩展区域、村民、文明历史和长期旅行内容。

**当前决策：先完成《消失的古道》纵切片并进行真实试玩，不扩地图、不新增大型模拟系统。**
